# ゲーム仕様

> [!NOTE]
> 仕様は実装より先にこのファイルで決める。未確定の項目は「未定」と明記しておく。

## コンセプト

- 花をモチーフにしたリバーシ系ゲーム(詳細は未定)

## 基本ルール

- 未定(標準的なリバーシ: 8×8 盤、挟んだ石を裏返す、置けない場合はパス、両者置けなければ終局)をベースにするか、独自ルールを加えるかを決める

## 遊び方のモード

- 未定(候補: CPU 対戦 / 同一端末での 2 人交代プレイ)
- オンライン対戦・ログインは扱わない(プロジェクトの制約)

## 保存するデータ

`localStorage` にのみ保存する。キーは `flower-reversi:` で始まる。

| キー | 内容 | 状態 |
| --- | --- | --- |
| `flower-reversi:visits` | 訪問回数(動作確認用、ゲーム実装時に削除予定) | 実装済み |
