# ゲーム仕様

> [!NOTE]
> 仕様は実装より先にこのファイルで決める。未確定の項目は「未定」と明記しておく。

## コンセプト

- 石の代わりに **花** を置くリバーシ。
- **赤の花はゴージャス**(幾重にも重なる花びら・金の花芯・きらめき)、**青の花は可憐**(小さな5枚花びら・白い花芯・ふんわりした花びらの舞い)。
- 花を置く瞬間と裏返る瞬間の演出を、このゲームの一番の見どころにする。

## 基本ルール

標準的なリバーシのルールに従う。

- 盤面は 8×8。初期配置は中央4マスに赤青2つずつ(d5・e4 が赤、d4・e5 が青)。
- **赤が先手**。
- 相手の花を自分の花で縦・横・斜めに挟める場所にだけ置ける。挟んだ花はすべて自分の色に裏返る。
- 置ける場所が無いときはパス(自動)。両者とも置けなくなったら終局。
- 終局時に花の数が多いほうが勝ち。同数なら引き分け。

## モード

| モード | 内容 |
| --- | --- |
| 一人用 | CPU と対戦する。自分の色(赤/青)と難易度を選ぶ |
| 二人用 | 1台の端末を交代で使う。手番が変わるたびに「交代画面」を挟み、次の人がタップしてから盤面を表示する(設定でオフにできる) |

オンライン対戦・ログインは扱わない(プロジェクトの制約)。

### 難易度(一人用)

| 難易度 | CPU の考え方 |
| --- | --- |
| かんたん | 置ける場所からランダムに選ぶ |
| ふつう | 角を好み、角の隣を避ける。1手先だけを見る |
| むずかしい | 数手先まで読む(αβ探索)。盤面の位置の価値と、置ける場所の多さを評価する。終盤は最後まで読み切る |

## 演出

| 場面 | 赤(ゴージャス) | 青(可憐) |
| --- | --- | --- |
| 置く | 回転しながら花開く。金色のきらめきと赤い花びらが舞う。盤面に波紋 | ふわっと膨らんで咲く。水色の小さな花びらが舞う。盤面に波紋 |
| 裏返る | 置いた場所から近い順に、時間差で立体的に回転して色が変わる。裏返った花から新しい色の花びらが舞う | 同左 |
| 音 | 厚みのある和音のチャイム | 軽く澄んだ単音 |

- 音はブラウザ内で合成する(音声ファイルを使わない)。オン/オフを切り替えられ、設定は保存する。
- OS の「視差効果を減らす」設定が有効なときは、動きを最小限にする。

## スコアとポイント

### 対戦記録

| 対象 | 記録する内容 |
| --- | --- |
| 一人用(難易度ごと) | 対戦数・勝ち・負け・引き分け・最高スコア |
| 二人用 | 対戦数・赤の勝ち・青の勝ち・引き分け |

### スコアの計算(一人用のみ)

1 試合のスコア = (終局時の自分の花の数 + 勝敗ボーナス) × 難易度倍率

| 項目 | 値 |
| --- | --- |
| 勝敗ボーナス | 勝ち 20 / 引き分け 5 / 負け 0 |
| 難易度倍率 | かんたん ×1 / ふつう ×2 / むずかしい ×3 |

- 獲得したスコアは **花ポイント** として貯まる。花ポイントはパワーアップ(花の庭)で使う。
- 二人用ではスコア・ポイントを付けない(勝敗の記録のみ)。

### リセット

- 記録画面の「記録をリセット」から、対戦記録と花ポイントをすべて消せる。
- 誤操作を防ぐため、確認ダイアログを出す。
- 設定(音・交代画面)と、花の庭で解放済みのもの・選択中のものは消さない。

## パワーアップ(花の庭)

花ポイントを使って **見た目を解放する**。勝敗には影響しない。

- タイトルの「花の庭」から開く。解放済みのものは、いつでも切り替えられる。
- 解放すると、その値段ぶん花ポイントが減る。花ポイントは「今持っているポイント」を表す。

| 種類 | 初期 | 解放できるもの(花ポイント) |
| --- | --- | --- |
| 赤の花 | ダリア | 椿(200)・牡丹(600) |
| 青の花 | ネモフィラ | 桔梗(200)・紫陽花(600) |
| 盤面 | 芝生 | 夜の庭(300)・桜の庭(300) |
| 演出 | 標準 | 花吹雪(500): 舞う花びらときらめきが倍以上になる |

- 花の種類が変わっても「赤はゴージャス、青は可憐」の方向性は保つ。
- 1 試合で得られるスコアの目安は、かんたん 30〜60、ふつう 60〜140、むずかしい 90〜250。数試合で 1 つ解放できる値段にしている。

## 保存するデータ

`localStorage` にのみ保存する。キーは `flower-reversi:` で始まる。値は `{ v: スキーマバージョン, data }` の形。

| キー | 内容 |
| --- | --- |
| `flower-reversi:records` | 対戦記録と花ポイント |
| `flower-reversi:settings` | 音のオン/オフ、交代画面のオン/オフ、前回選んだモード・色・難易度 |
| `flower-reversi:garden` | 花の庭で解放済みのものと、選択中のもの |

## 画面

1. **タイトル**: モード(一人用/二人用)、一人用なら自分の色と難易度を選んで「はじめる」。記録画面・花の庭・音の切り替えへのボタン。
2. **対局**: 上部に赤・青それぞれの花の数と手番表示。中央に盤面。置ける場所は小さな点で示す。下部に「やめる」ボタン。
3. **交代画面**(二人用): 「青の番です。端末を渡してください」→ タップで盤面に戻る。
4. **結果**: 勝敗、花の数、(一人用なら)獲得スコア・最高スコア更新表示。「もう一度」「タイトルへ」。
5. **記録**: 対戦記録と花ポイントの一覧。「記録をリセット」。
6. **花の庭**: 種類ごとに見本と値段を並べる。「解放」「使う」「使用中」を切り替える。
